# ONCO-301 Protocol Synopsis (Simulated Study)

> Mock protocol for a portfolio Clinical Data Management project.
> No real patients or drugs. All data is simulated.

## Study design
- Phase II, open-label, single-arm trial
- Disease: HER2-negative metastatic breast cancer
- Planned enrollment: 30 subjects, 2 sites
- Subject ID format: ONCO301-###

## Endpoints
- Primary: Objective Response Rate (ORR) using RECIST 1.1
- Secondary: safety (adverse events graded by CTCAE v5.0)

## Eligibility
- Age 18 or older
- ECOG performance status 0 or 1
- Written informed consent given before enrollment

## Treatment and key dates
- Informed consent date: before enrollment
- First dose date (C1D1): reference for adverse event onset
- Treatment in 21-day cycles

## Assessments
- Laboratory tests at screening and each cycle
- Tumor assessment every 6 weeks (RECIST 1.1)
- Adverse events recorded from first dose
